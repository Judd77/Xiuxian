# 剧情事实与待定问题

本页提炼当前十日切片中仍有价值的设定，供下一版谜案设计使用；不是要求原样续写十日日期链。最新玩法与主题见 `GAME_REDESIGN.md`。

## 现有切片中的事实

- 登仙帖背面有被刮去的旧名，失踪名册与炉房账目互相矛盾。主角可从名册、林月的动向或山腹共鸣进入调查。
- 阿澈是炉中活人证词的来源；救他与取得完整原始炉账在旧切片中形成取舍。证词、账目与阵图应保留各自的证据价值，不让某一份资料自动解释全部真相。
- 沈砚曾协助绘制旧阵，也是旧名册上的“死者”。他想救炉中人并寻找替阵方法，但不能抹去参与旧阵的责任。
- 林月优先救出仍活着的弟子，掌握离山路线；过早公开可能切断撤离机会。她不能独自救走炉中所有人。
- 顾衡知道旧阵以弟子承压，仍以此保护山下村落；他不肯拿村民性命赌未经验证的新阵。他的底线须在正面冲突中成立，而非写成无理由阻挠。
- 贸然停炉会使山脉裂隙失控。旧版第十日的第一次替阵试验失败，村落护符、撤人、原图与公众知情留下不同后果；这不是全游戏结局。

## 新版必须回答

1. 司籍弟子的工作范围如何使主角发现异常，又为何不能靠职务直接取得所有证据？
2. 朱印共鸣、辨气、灵识与阵理各能证明什么、不能证明什么？证人与术法证据发生冲突时，玩家如何验证？
3. 旧阵为什么必须在某个有因果依据的期限续阵？停炉、维持、替阵与撤离各需要什么准备，谁承担代价？
4. 玩家首次产生的错误判断是什么？哪一处可亲手验证的证据推翻它？对质后人物与行动怎样变化？
5. 每种结局如何兑现“问心”：主角学到的本领具体改变了什么，获救者与承压者分别是谁？

上述问题尚无定稿，不得把旧版事件顺序、三十日倒计时或四结局条件直接视为新剧本的既定事实。

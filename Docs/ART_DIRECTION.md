# 第一日美术制作

## 本轮状态

CC0 古画衍生图用于验证画面与阅读布局，后续保留作标题或章节过渡的候选。它不替代剧情需要的具体地点背景。角色立绘仍缺失。

原创资产采用统一的东方绘本方向：清楚的服饰和环境结构、低饱和青绿、灰白雨雾、少量朱砂和暖灯光。不引用现有游戏角色，不指定模仿在世画师，不描摹来源不明的网络图片。

## 待执行生成规格

### 雨夜山门

用途：第一日开场、行动前后的全屏背景。1920×1080 或更高的 16:9 位图。

提示词：原创中国修仙悬疑视觉小说场景，三日连雨后的青云山门，古朴灰瓦石门、湿润石阶、远山与松树，门侧一盏暖色灯和无可读文字的朱红告示，低饱和青绿与灰白为主，东方水墨设色绘本质感，建筑结构清晰，平视广角，无人物，无水印、标志、界面或文字。主要山门放在画面中上部，底部三分之一较安静，供游戏叠加对白。避免日式鸟居、现代设施及现有 IP 标志。

### 林月立绘

用途：第一日与林月的对话。透明 PNG，建议 1024×1536 或更高；保留头发、袖摆和裙摆边缘。

提示词：原创成年中国修仙女性角色林月，外门师姐，沉静而有所隐瞒，实用素雅的灰青交领长衫与墨绿束腰，简单木簪束发，携带收好的行囊，服装层次与手部清楚，自然站立，轻微面向画面左侧，东方绘本式精细线条与柔和设色，柔和中性光，完整人物不裁头脚，透明背景，无文字、水印、标志，非现有影视或游戏角色，不模仿特定在世艺术家。

验收：背景结构和人物手部、透明边缘、画布与站位、服饰一致性、实际对话遮挡、资源导入及来源记录。未生成前不得把提示词当作已完成资源。

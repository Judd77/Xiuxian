# 美术方向

当前视觉基准：清透云海与青绿山水、水墨设色质感，玉白、青黛、暖金为主，朱砂少量强调。人物为年轻化半写实国风立绘；UI 保持现有首页与玩法界面的统一层级、清晰对比和水墨质感。可参考同类商业修仙游戏的完成度，不能复制其角色、标志、图标、构图或界面资产。

## 角色与场景

- 半身 AVG 站位由 Unity 放大全身透明源图并贴住屏幕下沿形成，不另裁切源图。不同表情保持画布、头身、光源和锚点一致；人物不能漂浮或遮住重要文字。
- 背景应明确展示剧情地点，给立绘和对白留出可读区域。切换地点时同步更换背景；雨雾与仙气特效服务于场景，不妨碍文字辨识。
- 已接入林月、顾衡、阿澈、许澄、沈砚五人立绘，以及山门、松风岭、旧碑廊、弟子居所、山腹石门、医舍、南沟村、议事堂、炉房和谷口背景。南沟村有日景与暂守用夜景；谷口有日景、撤人夜景及改道后药田损毁画面，保持同一地形。炉房可见炉、石柱、通向窄榻的石槽和停铃，帮助解释阵流。四名新角色以林月为材质参考，保留 API 返回的原生透明通道；顾衡站姿、阿澈与许澄病弱坐姿、沈砚持图册。工匠家、村民家、许家、旧钟楼与司籍房专图已接入；分别保留护符、药碗、玉扣、守钟原簿和名册的场景道具。仓房、交接台与考校台也已接入专图，灰样观测仍由运行时演出显示。五种关键表情差分已接入，详见下节。
- 新的术法演出应让玩家看清修仙能力带来的信息变化，例如灵气残痕或阵纹显现；不以装饰特效代替调查反馈。

## 已接入的关键表情

2026-10-12补齐五种必要差分：林月担忧（潜入与救援）、阿澈不安（回忆受困）、顾衡愧疚（承认旧呈报）、沈砚愧疚（承认迟停）、许澄坚定（要求停铃在手边）。首次正式版21节点、Demo 10节点按剧情使用；revision 36主线对质沿用沈砚和顾衡差分增加6节点，现正式版27节点，其余页面保留基础立绘。

通过已授权API及指定模型gpt-image-2.5-sunburst，分别编辑项目自有立绘的面部。最终资源只合成羽化面部区域，区域外RGB及整张原图Alpha保持；1024×1536画布、人物姿势、衣服和Unity站位一致。完整提示词、输入蒙版、源图、加工与哈希见 `AssetResearch/character-expressions-api.json`；`Tools/prepare-character-expressions.py`可重现合成，不调用API。

## 资源准入

优先使用项目专用原创生成资产或明确允许商业使用的素材。生成过程、源图、加工、哈希与授权依据见 `ASSET_PROVENANCE.md` 和 `AssetResearch/`。不要指定模仿在世画师或复刻现有游戏角色。导入后在 Unity 中检查透明边缘、裁切、文字可读性、立绘贴底与分辨率适配；概念图不能直接算成品。

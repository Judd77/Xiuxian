# 下一步制作

1. **审读正式故事与剧本。**按 `STORY.md`、`GAME_SCRIPT.md` 核对每条路线的时间、谁掌握何证据、术法限制、人物同意及终局代价。修正任何故事与玩家可操作内容不一致处；由未参与写作的人朗读开局，标出听不懂的术语和不自然的对白。
2. **逐屏审读并补足路线独有体验。**共通首案、三条调查路线与六种结局链已进入 revision 26，但这只证明主要路径能从头走到尾。林月线的家书、守卫、证词、停铃后果和议事堂证据判断，顾衡线原簿归属、补符、村民拒绝试阵与议事堂逐笔归责，以及沈砚线周望证词、迟停记账和停止试验的后果已补进游戏；下一项审查沈砚路线在议事堂的旧约、旧图与迁村证据，逐屏检查不同停铃状态下的对白和选项。每完成一条体验改进任务单独 Git 提交。
3. **完成演出与 Windows 交付验证。**正式版与 Demo 共用 revision 26 的首案与分界存档，旧修订号存档会提示版本不匹配。补医舍、司籍房、村议、观测台、炉门等专属背景和关键角色立绘，使证据与术法验证有可见反馈；在 Unity 窗口与 Windows 构建中检查画面、选项、存读档和 Demo 衔接。
4. **验证目标。**邀请未参与制作的玩家无提示多周目游玩，记录不重复的新鲜体验时间与阅读感受；不足三小时便扩写真正不同的案件行动、关系和后果。达到可玩质量后再处理 Steam 双 App、云存档、资产商用复核与发行。

目标是不同周目累计至少三小时新鲜游玩，不是三小时文本阅读。当前时长尚未由外部玩家测得，也未达到可宣称完成的状态。

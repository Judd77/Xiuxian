# 下一步：把短篇做成足量、可重玩的游戏

目标见 `GAME_REDESIGN.md`；故事正文初稿见 `INTEGRATED_STORY_DRAFT.md`；工程现状见 `DEVELOPMENT_STATUS.md`。revision 15 已接入新故事，但仍是短篇可玩稿，不是六小时成品。玩家希望读到互动式修仙小说，术法与选择服务故事，不靠临时调查节点凑时长。

1. **先在 Unity 实际通读 revision 15。**检查对白框里的字数、场景切换、人物立绘和每个分支的前后因果；目前仅完成工程副本的剧情图验证。把玩家看不懂、仅有说明书语气的段落改成可读场景。
2. **优先扩写三个互斥调查路径。**首案后“先救人”应有独占的侧门营救、家属关系与未救出者后果；“先查村”应让玩家亲自比较旧灾原簿、护符和撤离脚程；沈砚线应让玩家用停铃和阵路验证他的说法。每条都要有新发现与实质行动，不复制共同场景凑时长。
3. **把终局变成执行过程。**玩家须按所学术法、已知证据和争取的人手安排停铃、引流或救援，而非只选结局按钮。改道、夺台、维持旧阵分别兑现准备与责任；补齐林月之外的关键人物立绘及医舍、观测台、村口和议事堂场景。
4. **每项可玩内容单独提交并验证。**每完成一条完整场景链就检查 Unity 剧情图与画面。请未参与制作的人无提示游玩多个周目，记录新增体验时长和阅读感受；共通重读不计入至少六小时目标。达到质量后再处理 Steam 双 App、构建、云存档和商用资产。当前 Demo 不作为可发布内容。

# 问心劫（开发暂定名）
## 目标
Windows / Steam 单机修仙悬疑 AVG。商业名称未做同名/商标检查。好玩和销量不能保证，必须试玩迭代。
核心：外门司籍弟子从失踪名册与炉房账目的矛盾入手，学习并运用术法查证宗门仪式的真相，最终决定如何处理炉中弟子、山下村民与旧阵。玩家要亲自比较证据、验证判断，并为选择承担代价。完整体验目标与玩法基准见 `GAME_REDESIGN.md`。
“问心”是有能力改变局面后对责任的选择，“劫”兼指山脉灾劫与修行心劫。三十日日程、重复修炼采集和随机事件牌不再是既定玩法；剧情期限与案件数量待切片试玩验证。
## 开发约定
用户委托助手负责设计、技术选型、代码和资源制作，优先直接操作工程，不要求用户反复复制脚本。付款、账号、协议、最终发布仍由用户处理。
Unity 6000.6.2f1，URP，C# 9。UGUI + TMP + Input System。剧情采用轻量 JSON 节点，运行状态独立于 UI。离线可玩优先。
首发目标（尚未实现）：从开局到结局完整、可玩的修仙悬疑 AVG；三位主要人物关系线、多个相互关联的谜案、可调查地点和有代价的结局。玩家可通过多周目累计获得至少六小时持续有趣的**新鲜体验**，不要求首次通关独占六小时；不同周目须有实质不同的证据、行动、人物关系与后果，共通剧情的重读不计时。由未参与制作的人试玩计时和访谈验证。不做开放世界、复杂战斗、全语音。
## 第一阶段
当前工程已经接出一版从开局到结局的短篇可玩结构，仍远未达到六小时目标。林月、顾衡、沈砚底稿与公开调查有不同场景，并可进入裂隙试验与四种结局方向；旧十日素材只作隐藏的开发入口。临时案件名称和具体证据链不是用户确认的既定剧情。下一阶段要把各案扩写成真正值得多周目体验的完整内容；每段都应贡献新的发现、能力、人物冲突或有后果的行动。
视觉方向：低饱和青绿、旧纸、朱砂强调。原创东方绘本风。中文字体需明确商用许可。

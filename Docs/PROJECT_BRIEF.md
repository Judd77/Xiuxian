# 《问心劫》项目简报

## 作品

Windows / Steam 单机互动式修仙悬疑小说。世界是古风宗门与山下村落；“现代”指参考 2020 年以后成书作品的阅读节奏、人物关系和信息揭示方式，不指现代都市背景。所有人物、情节、设定与文字原创，不照搬参考作品。

玩家作为外门司籍弟子，从阿澈失踪与离山记录缺印开始调查。玩家比较来源不同的证据，学习有明确边界的术法亲自验证，再决定如何救炉中人、保护山下人和处理旧阵。小说的阅读兴趣优先，玩法让判断与后果变得可参与；修仙能力必须改变可见信息和行动能力，不能只是特效。

完整故事、人物真相和结局以 `STORY.md` 为准；逐场对白、玩家操作、证据条件与演出以 `GAME_SCRIPT.md` 为准。两者是正式制作依据。Unity revision 34 保持为共通首案、山下调查、议事堂对质与改道／公开暂守两个结局。林月、沈砚仍参与主线，独立路线及离山、夺台、隐瞒结局延期；原内容由 Git 提交 1e96cf1 保存。已接入辨气双样本、阵流先后与撤力／引流的画面反馈；继续补主线专属画面和实际游玩收尾。

## 体验目标

- 长期目标仍为累计三小时新鲜游玩。用户要求缩减范围、加快首发后，本版优先完成一条好玩的完整谜案；实际时长未测，不承诺已达三小时。商店时长按无提示试玩计时描述，不靠重读、等待或失败重试填量。
- 不采用固定三十日、重复养成、随机事件池、开放世界、复杂战斗或全语音。时间压力由石柱、炉符和村符的可测变化推动。
- 重要判断必须改变人物回应、取得的证据、可执行的行动或结局代价。玩家猜错仍可补证，但机会和信任会变化。
- 术法须在人物行动中学会：辨气分余息新旧，不识姓名；遮铃符只遮灵气铃七息；阵流小试只能测局部，须有人守钟并可叫停。
- 首发独立免费 Demo 与付费完整版使用两个入口场景、两份剧情数据；Demo 在卷一人物与村庄同时告急处结束，完整版继承调查状态；当前可接续 revision 33 的存档，保留原有选择和证据。共通首案、一条主线与两个结局链已录入；尚未达到可发行质量。

## 制作与授权

Unity 6000.6.2f1，URP、C#、UGUI/TMP 与 Input System。剧情数据与运行状态分离，Windows 离线可玩优先。用户委托助手负责设计、代码、美术资源和构建；账号、付款、协议及最终发布由用户处理。

美术保留清透云海、青绿山水、旧纸与朱砂的现有方向。已接入山门、居所、山腹、医舍、南沟村、议事堂与炉房背景；接着补谷口等调查地点与顾衡、阿澈、许澄、沈砚立绘。用户授权改用 API 出图，指定模型保持 gpt-image-2.5-sunburst。商用素材许可与生成记录见 `ASSET_PROVENANCE.md`、`AssetResearch/`；具体画面规范见 `ART_DIRECTION.md`。

## 文档入口

- `STORY.md`：正式故事母本，含共通剧情、山下调查、对质与两个首发结局。
- `GAME_SCRIPT.md`：正式逐场游戏剧本，含对白、证据、术法操作、条件和分支后果。
- `DEVELOPMENT_STATUS.md`：只记录工程已实现及验证事实。
- `NEXT_TASKS.md`：下一步制作顺序。
- `CODE_ARCHITECTURE.md`、`ART_DIRECTION.md`、`ASSET_PROVENANCE.md`、`AssetResearch/`：实现、视觉与授权证据。

# 问心劫：三十日登仙（开发暂定名）
## 目标
Windows / Steam 单机修仙悬疑 AVG + 有限日程养成。商业名称未做同名/商标检查。好玩和销量不能保证，必须试玩迭代。
核心：三十日后的登仙大典可能是献祭。玩家在修炼、调查、人际关系之间取舍，决定救人、逃离或改变仪式。
## 开发约定
用户委托助手负责设计、技术选型、代码和资源制作，优先直接操作工程，不要求用户反复复制脚本。付款、账号、协议、最终发布仍由用户处理。
Unity 6000.6.2f1，URP，C# 9。UGUI + TMP + Input System。剧情采用轻量 JSON 节点，运行状态独立于 UI。离线可玩优先。
首发范围目标（尚未实现）：三位主角关系线、约六个地点、四个主要结局、单周目约3–5小时，须实测修正。不做开放世界、复杂战斗、全语音。
## 第一阶段
先完成第一日《山门夜雨》：序章对话、两次行动、证据/信任/修为变化、至少两种后续、存档。先用占位资源，玩法通过再制作正式美术。
视觉方向：低饱和青绿、旧纸、朱砂强调。原创东方绘本风。中文字体需明确商用许可。
## 项目位置
根目录 D:/project/Xianxia。游戏内容放 Assets/_WenXinJie。保留原 Settings、Welcome 和 SampleScene。

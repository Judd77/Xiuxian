# 《问心劫》项目简报

## 作品

Windows / Steam 单机互动式修仙悬疑小说。世界是古风宗门与山下村落；“现代”指参考 2020 年以后成书作品的阅读节奏、人物关系和信息揭示方式，不指现代都市背景。所有人物、情节、设定与文字原创，不照搬参考作品。

玩家作为外门司籍弟子，从阿澈失踪与离山记录缺印开始调查。玩家比较来源不同的证据，学习有明确边界的术法亲自验证，再决定如何救炉中人、保护山下人和处理旧阵。小说的阅读兴趣优先，玩法让判断与后果变得可参与；修仙能力必须改变可见信息和行动能力，不能只是特效。

完整故事、人物真相和结局以 `STORY.md` 为准；逐场对白、玩家操作、证据条件与演出以 `GAME_SCRIPT.md` 为准。两者是正式制作依据。Unity revision 48 为共通首案、山下调查、议事堂对质与改道／公开暂守两个结局，共242节点。林月、沈砚仍参与主线，独立路线及离山、夺台、隐瞒结局延期；原内容由 Git 提交 1e96cf1 保存。已接入主线地点背景、辨气双样本、阵流先后与撤力／引流反馈；已补沈砚、周望正式出场并修正叙事衔接，在编辑器从开场走到改道结局。五种关键表情已接入；H04已扩为三项主动举证与完整证词；G07已加入查柱位、交换探路符、执行停钟与裂符代价；H05已补许澄本人确认、关闸演练与迟撤回应，正式救人前试两人停铃和石台回钟，第三声后完成撤力、出炉与损耗交代。revision 39新增改道后的医舍／安置／欠账，以及公开暂守的三方交付／本榻轮换／再试条件；已在当前Unity编辑器Play中接续revision 38快照走完新增结局，确认损耗变体、记录交付和停铃选择，查看两张关键画面。按用户最新指示，当前集中制作主线，Demo和发行工作暂缓。

## 体验目标

- 当前revision 48、242节点，主线、两结局、结局页操作及整体演出已接入，按既有功能权重总体85%。钟楼试传、考校案房核签与阿澈医舍证词调查已接入；证词可当场核对，也可在议事堂由本人补正。正式全部节点的基础正文合计约2.2万字，三小时新鲜体验仍缺少时长依据，后续继续扩充主线内容并取得真实玩家计时。本轮完成灰样、断符、旧灾、柱位、对质和引流六处推理场景的整批调整，共23个既有节点；Unity已实际运行指定流程及44通关档接续。剩余为无提示玩家试玩、计时与反馈处理，发行工作暂缓。三小时目标仍未证实。

- revision 43已统一修订山下答复、白天试走、村议名单、期限依据和旧号取证五场共19段正文及相关选项，仍208节点；选择前交代来源与条件，结果页保留实际记录时机。主线与两结局均已录入，当前按整批场景统一打磨，再做玩家计时，辅助功能不再扩充。

- 前尘现可随手动／自动存档接续，记录实际读到的正文与成功选过的选项，方便回查证词和判断。失败／取消读取保留本次记录，新开局重置；旧档未保存的历史不会回填。阅读历史不参与剧情规则，剧情仍revision 42、208节点。

- 已实现独立自动存档：新开局、翻页和选择后保存当前进度，首页可恢复自动或读取手动书签；没有本次会话时继续较新的有效记录。写入失败保留当前游戏并提示手动存档。手动／自动使用不同文件，新开局提示会替换自动进度；当前剧情与存档schema不变。

- 已实现线索未读提示：新收录或有变化的记录保留到实际查看，底栏显示数量，打开线索簿定位最近一条，可逐条跳转；只反映本次会话，读档与新开局重建基准。剧情仍revision 42、208节点。

- revision 41在最后引流加入摆符、玩家主动辨气与错误接线后的重新确认，共205节点。玩家比较本次左右槽的余息，再选择送力位置；此前的石槽宽窄与旧图都不能代替本次术证。选错保留裂符、轻伤与额外符料，修补、看伤和重新确认意愿后才能继续。

- revision 40已把小试后决定、三户谈迁居与撤离顺序的11段正式文本重写，补齐各户的安置条件。选择前不提前写已答应或已出发；村口撤离钟与炉门停铃分别交代，三户线索只记先行要求。仍202节点。

- 主线线索簿隐藏尚未发现的关键标题，区分资料收录与确证。复测、补符、小试、停铃与出炉的记录随已执行行动更新，保留损耗；不会在第三声传停前显示救人完成。

- 长期目标仍为累计三小时新鲜游玩。用户要求缩减范围、加快首发后，本版优先完成一条好玩的完整谜案；实际时长未测，不承诺已达三小时。商店时长按无提示试玩计时描述，不靠重读、等待或失败重试填量。
- 不采用固定三十日、重复养成、随机事件池、开放世界、复杂战斗或全语音。时间压力由石柱、炉符和村符的可测变化推动。

- 已接入四档文字速度与自动阅读。自动翻页遇选择等玩家决定，查看前尘／线索时暂停；新开局、读档、主界面与结局关闭自动模式。速度偏好独立保存，不改变剧情或用等待补时长。

- 首发独立免费 Demo 与付费完整版使用两个入口场景、两份剧情数据；Demo 在卷一人物与村庄同时告急处结束，完整版继承调查状态；正式版声明兼容 revision 33—47 的存档；revision 48 的证词变量对旧档补初始值，保留原有选择和证据。共通首案、一条主线与两个结局链已录入；尚未达到可发行质量。

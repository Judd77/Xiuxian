# 决策记录
- 游戏主体是有时间代价的剧情选择，不是无限刷数值。
- 关键判定使用确定性条件，避免靠读档刷概率；失败也应有叙事反馈。
- 日程、关系和证据状态与场景对象分离，便于测试和存档。
- 先实现规则原型，再加 JSON 剧情演出和 UGUI/TMP 展示；不能把规则原型当成可玩商业版本。
- 新资源和脚本集中在 Assets/_WenXinJie，文档放根目录 Docs。
- 已通过官方 Unity 编辑器执行接口实际运行 C#；不要再引导安装第三方 Unity MCP。
- 当前会话有 Unity 读写/执行/Console/生成工具；新会话须重新核查可用工具。
- Unity AI 包内官方 MCP 文档标记弃用、推荐 CLI，但目前已连接成功，无需为迁移而迁移。
- 网络搜索曾失败，不虚构已核实的最新 API、Steam 政策或授权。
- 正式美术生成先告知具体资源、等待阻塞与耗时不确定性并获得首次确认；购买另行批准。

- 临时UI采用UGUI Text加载本机字体以先运行中文原型；不分发系统字体。最终仍按TMP和授权中文字体计划实现。

- 用户明确指定设计分辨率1920×1080。Canvas参考尺寸、坐标、字体和按钮已同步升级，固定设计框居中，Expand保留非16:9余量。

- 2026-09-22 用户要求遵守 Rider C# 规范与可读的游戏结构。新增根目录 `.editorconfig`；采用轻量 Model / View / Presenter 职责分离，具体约定见 `CODE_ARCHITECTURE.md`。
- 2026-09-22 首批外部资源优先采用明确 CC0 的馆藏画作及作者上传音频。原图保留、修改可复现、游戏内鸣谢；不把修改当作消除侵权风险的依据。

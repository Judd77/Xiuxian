# 《问心劫》正式游戏剧本

本剧本以 `STORY.md` 为唯一剧情母本。场景编号是长期稳定的制作索引，不按 Markdown 段落自动切节点。每场写玩家实际读到的文字、可操作的选择、必要的证据条件和行动后果；程序可以把一句对白分屏展示，但不得凭切屏数补时长。首发范围为共通 C01—D00、山下调查 G01—G09、议事堂 H01—H06、改道 E01—E05 与公开暂守 E30。Unity revision 59 为一条主线、两个结局；独立林月／沈砚路线和离山、夺台、隐瞒结局延期，原稿保存在 Git 提交 1e96cf1。新鲜游玩时长尚未测得，当前不承诺已经达到三小时。版本号只用于识别剧情数据与存档，不表示章节数或游玩时长。

## 共通规则

- 主角在进入游戏前会基础吐纳，不需要玩家刷修为。辨气由入门书习得，遮铃符由林月教，首发不单设听脉教程，引流与阵路复测由顾衡主线教。学过的本领要在后续行动里再次使用。
- 辨气只辨近期余息和新旧，不识姓名。听脉隔薄墙可知有人呼吸，不识身份。遮铃符遮住依灵气感应的铃七息，遮不住视线。引流小试只展示局部先后，旧图不能代替现场。每条限制都要在玩家可能误用之前演出。
- 证据分“亲眼所见”“当事人说法”“术法所测”“尚未证实”。线索簿逐项写明来源与边界，不替玩家自动定罪。错误推断导致人物质疑、资料被封或时间损失；仍有代价明确的补证路，不用答错即死。
- 没有好感度与每日行动数。人物合作取决于是否说明真实风险、是否保留证据、是否履行承诺。没有随机案件；灵潮期限由符料、村符与石柱记录共同显示。
- Demo 在 D00 停止，保留全部证据状态。完整版从 D00 跟顾衡下山；Demo 结束文本不可覆盖完整版入口。
- 结局由执行过程形成。改道需要迁路实测、旧阵复测、炉中人的停铃权和联合记录；缺一项便要选择别的可执行办法。公开暂守须执行撤人、补符、换药与轮换，不只显示结局标题。

## 卷一：没有下山的人（共通；Demo）

### C01 药碗

地点：弟子居所。立绘：无。目的：在半分钟内让玩家关心阿澈，而非先读世界说明。

旁白：阿澈的药还温着，人不在屋里。玩家是替司籍房抄册的外门弟子，阿澈住隔屋，这碗药是玩家替他领的。床底有一只开线的左脚鞋。昨晚他还抱怨宗门的鞋不经穿，说等病好了要找你报换。

管事出示销名单时，先交代离山须销名、持登仙帖去山门验印；登仙帖是弟子入门时领的身份凭帖。玩家知道这层手续后，才出现“谁验帖”“走哪条山路”的追问。

管事：“他家里有事，天亮前下山了。病好了自然会回来。”

你：“他没穿这只鞋。”

管事：“你若事事都管，明日考校谁替你去？”

玩家可选择问“谁替他验了离山帖”或“他走哪条路”。前者得到管事的销名时辰；后者得到模糊的“北道”，并看见管事不愿看那只鞋。两种问法都让主角去查山门，不在此奖励猜中绑架。

### C02 两本册子

地点：山门簿案与司籍房。画面：山门朱印特写，随后是两张纸并列。目的：第一次证据比较。

旁白：宗门弟子离山先销名，后在山门按灵力印。名册上阿澈已销名；山门阵石相应的一格空着。守门人不让你碰原阵，你只能查抄簿。

同页另一名昨日真实回家的弟子有完整朱印，登仙帖纸边也有门阵焦痕。玩家先把真实离山与阿澈的记录并排，才能将“少了验帖”记作可追问的手续异常；不能仅因一格空白便断言宗门绑人。

玩家以昨日完整朱纹与阿澈空印比较、直接指控管事藏人，或用药碗追问。直接指控会让守门人收起原页；药碗不能证明去向，两路仍可抄真实离山者的印，回到手续核对。用印位核对后他签查阅时辰，并承认没有见阿澈过正门。任何路线都保留矛盾：没有门印并不证明他没有走山中小路。

线索簿：离山手续矛盾（亲见两份文书）。

### C03 帖背旧名

地点：司籍房。画面：纸举向灯，“砚”字从薄处露出。

旁白：你自己的登仙帖背面被刮薄了。残墨里剩一个“砚”字。十年前山灾册写“沈砚，失踪，推定身故”。旧帖再用并不违规，刮得这样干净，像是不想让下一位拿帖的人看见旧名。

选择“拓下刮痕”可保全原纸，后续与旧号领单、更名册核对；选择“先去问管事”会让他知道你在查帖，仍可由陈闻取得一张旧号领单。两路都不能据此宣称沈砚尚在人世。

### C04 瘸鸟纸角

地点：医舍外到山腹坡道。画面：车沿包药纸、守卫与石门。

旁白：药车沿挂着一片纸，折角像只瘸鸟。昨晚阿澈笑你包药时手笨，正是这样折的。守卫伸手拦在坡道前，你看不到车厢里有什么。

玩家可保留纸角并记车次，或当面质问守卫。质问会使今夜侧门多一次巡查；记车次可让陈闻对上交接记录。两种选择都不把“纸角来自阿澈的药”升级为“阿澈在车上”。

### C05 辨气入门

地点：弟子居所。玩家知道左符刚画废、右符搁了三日，选择先用新符校准还是省去对照先摸旧符。省略对照时指尖麻与纸上余息混淆，歇过后重新比较；不要求把明知日期的旧符猜成新符。完成后得到辨气本领，只辨近期余息而不识姓名，后续用同批灰与柱位再次应用。

### C06 运车灰样

地点：仓房与山腹坡道。画面：两份灰并列，灵气只在运车灰上浮现。

旁白：仓房的灰与车沿刮下的灰来自同一批。你用刚学会的辨气逐份试。运车灰有今天新沾的灵气，仓房灰没有。

revision 45让玩家决定下一步取证：按车牌追交接、先复核封签与领灰时辰，或把纸角与新息合记为阿澈乘车、请陈闻确认。前两项分别取得交接出处与未换批的来源核对；第三项由陈闻以药纸可随箱上车、守卫今日用灵力验牌说明证据仍不足，玩家划去姓名。c06.batch不再要求玩家否认已知的同批封签。陈闻随后交出自己签过的运料单，核对纸角与车牌；不增加好感或存档变量。共通文本同步Demo，不扩其范围。

### C07 考校副册

地点：考校台。画面：副册“阿澈”被朱笔重重划掉。

执事：“抄错了，改掉便是。”

旁白：正册说他已离山，副册仍等他应试。你心神不定，符纸在台上烧成青烟，身后有人笑。你再看副册，那道划线透到了下一页。

玩家可趁退场时抄下副册归档时辰，或追执事询问谁通知改名。前者取得可与山门簿并列的文书；后者得到执事的“管事口头告知”，也使对方记住你。两路汇于c07.margin，玩家可先找陈闻查二更运车，或追问考校台何时收到销名通知。

revision 47新增9节点的案房调查。值日抄手展示誊错的半张通知，验帖印栏仍空；副册晨间已在台上，销名签收排在点名之后。玩家可先以辨气比较今日划名与旧纸余息，再核送达时辰；术法不认下令人，也不能证明阿澈仍在山上。把晚到通知当作仍在宗门的旁证，会被抄手指出自己未见他上山或下山。玩家得到由抄手亲签的三处时辰，case.deputy由原有0／1扩至2，2表示核到通知送达；旧存档的0／1和Demo导入仍有效。C08陈闻回应晚到通知与旧号领单的不同证明边界；H04祁元肃去向项在2时让抄手当堂核签，但仍须用医舍伤签、山门空印和阿澈本人核实际去向。案房探查不改变原来救人结果，且可被跳过。

### C08 陈闻的旧号

地点：交接台。立绘：陈闻待制作，可先以剪影表现，不用林月立绘代替。

陈闻：“车进去时重，出来时轻。我只见过车，没见过人。”

旁白：陈闻负责夜间运料交接，是玩家抄册时常核车次的人，先在仓房收废符时介绍；考校散后，玩家主动去交接台问他。领料单沿用沈砚的旧号，不同签收人的笔迹却不同。陈闻将旧号划给你看：“这个号，谁拿笔都能用。”

revision 52新增13节点。玩家可先核二更车的出入页，也可先核同号两张领单，最终两项都要看。出入页同车牌、同一交接班，车出来较轻；药料卸入炉房也能解释重量差，陈闻没见车里的人。旧号两张领单的日期、用途和签收字迹不同；近日领炉灰一页无榻号，不能由号码推出沈砚本人在炉里。各项均可先越证再由陈闻指出具体缺口并划去人名。汇总时玩家决定分写两种来源，或误合成“阿澈在车上、沈砚在炉里”再纠正。陈闻最后亲签车牌、时辰、签收者和自己见证范围，原簿仍锁交接台；c08.receipt才置case.transferRecord=1，H02查更名册与H04旧号质询按实际取得的抄页回应。旧revision 51及更早存档给三个新调查变量补0，不追认已取得新抄页；Demo不扩。两路均接林月药箱，不因旧号断定沈砚活着。

### C09 林月的药箱

地点：医舍。林月认出药纸，先只说血是阿澈搬箱留下，不提前揭示箱子返回日期。玩家先查领用单，或把血误记成昨夜；领用单与林月亲历说明箱子前天已回、血更早留下。先查与更正均接送药侧门计划。

计划说明二更交接、探气铃与七息遮铃的限制：符只遮灵力感应，守卫仍能看人；正门须先报管事可能让人被转移。没有反复读秒小游戏。

### C10 七息进门

地点：侧门。case.guardAlert=1时显示守卫认脸、多巡一趟的正文；两个进门选择仍可执行。决定前明确立刻进门可能暴露车牌、陈闻报错会失交接差事；等待则耗尽最后一张备用符。

case.chenJob／case.secondTalisman在各自c10.now／c10.wait结果页记录，取消选项上的重复提前置位。救出后c11.cost回应陈闻失差；C13再次到门前时耗尽符者须等正常送药开门；改道尾声e05.orders／e05.winter分别保留陈闻个人抄页与林月补买符的后果。不会因转章清零。

### C11 阿澈的床

地点：炉房外榻。先说明炉中烧药符、石槽连山阵，弟子用基础吐纳疏导乱气，腕符将人接入阵中，来不及疏导伤经脉。

林月先说只松符带少许，玩家沿石槽辨气；实际松半寸后石柱新息先增、隔壁侧随后发暖，所得是本次挪带的局部反应，不是辨气预测未来。立刻扯符带则烫手，经林月拦阻后补看。随后可多留片刻抄门边两张榻号，或直接带人走；榻号不是姓名，两路均未绕墙亲见隔壁人。

救人用空药车承载，以药箱和布帘遮住阿澈；不把成年人塞进普通药箱。抄号结果c11.number置case.bedNumber，保留警铃提前的后果；随后医舍收到村口报信，裂符已补、无人受伤。陈闻失差的状态在这里首次得到事后回应。

### C12 隔墙两下

地点：医舍。阿澈发烧，记忆不可靠。

你问床底那只鞋。阿澈：“是我踢进去的。他们让我把被子叠好，像自己走的。我知道你会来送药，怕你只看见一张离山单。”鞋证明他有意留下求救痕迹，不证明隔墙人的姓名。

revision 48在鞋后加16个医舍节点。玩家可先问伤腕，再看刚解下的旧带与未用新布，主动辨气比较两物今日余息；也可先核药签与留榻纸。两条顺序都会查完两项，再与阿澈口述对照。旧带有今日新息，只证明今天仍承气；药签写他领安神药，留榻纸同意栏空着，不能把领药推成自愿坐榻。阿澈记得发烧后又被领回，问过能否起身；他没看清背灯者的脸，不可替他填姓名。

玩家在c12.record决定当场请阿澈逐句口述、林月读回并按印（case.acheTestimony=1），或先注明“本人未核”让他服药歇下（=2）。两项都保留阿澈对留榻的否认；后者在议事堂h04.qiRecord必须由阿澈本人补正、姐姐读回后才作正式证词。revision 47及更早兼容存档缺该变量时迁入初始值0，旧剧情位置保持；Demo不扩写。线索簿在问隔墙前只显示留榻相关内容，不能提前泄露敲门。

随后才问隔墙。阿澈：“门上好像写‘沈砚’。里面的人每回敲两下。后来我听到一个‘澄’，也许是药让我听错。”

玩家记录可写“沈砚在隔壁”或“身份未明”。若写前者，林月直接追问“门上的旧漆能替今天住在里面的人报名吗”，阿澈说明自己服药后连听到的“澄”字也不确定，玩家亲手更正。若写后者，林月问阿澈是否带出别的东西，他才拿出玉扣。纠正依据来自旧名与当前住人的区别、证词的听闻边界，不插入与该推断无关的药箱辨气。救出阿澈时始终没有绕过隔墙看清另一人；后续如实回答姐姐的“不曾亲见”与救援旁白一致。

### C13 半枚玉扣

地点：许家。姐姐名许蘅，沿用许家背景；立绘待制作。

陈闻：“许澄多年前领过这种配绳。”

许蘅：“另一半在我这里。合得上，也可能是旁人拿她的东西。她还能自己说话吗？”

revision 49把许家扩为可玩调查：进入后可先核陈闻的旧领绳单，或先核两半玉扣的断口；两路都到c13.sources归纳三种来源。断口只证明原是一块，旧单只证明许澄曾领同纹配绳，阿澈只见一只递扣的手。c13.infer让玩家写“持扣人待亲问”或先认定为许澄；后者由许蘅和阿澈当场指出越证，玩家亲手划去，不把术法或玉扣写成万能认人。story.xucheng在实际比对结果页才置位。

许蘅接着问救人会否让村符再裂。玩家可照报信说明阿澈离榻后裂一符、工匠补牢且无人受伤，同时承认下一股落点未知（case.familyDisclosure=1）；也可暂时不说裂符（=2）。后一选择在顾衡带新裂符到侧门时由许蘅当面追问，钥匙停在锁孔外，后续h05.split见许澄时她要求玩家把村口停钟人念给妹妹听。旧存档迁入值0，不虚构已经说过。许蘅听到代价也不会直接放弃妹妹，仍先听本人回应并要求村口能叫停。

玩家最后回答“隔墙有人敲门，未亲见”，或夸大为“我确定她在”。如实回答，许蘅同意带备用钥匙来；夸大后她仍来，但要求先让她自己听见妹妹回应，在c13.door实际回应等本人确认导致巡廊逼近；h05.split再见许澄时她仍要求妹妹自行报姓名。两项旧后果与是否交代村符可组合出现。

### D00 两声敲门与碎符（Demo 边界）

地点：山腹侧门与南沟村口交替。门里两下敲击，村口符裂。顾衡带着符灰赶来。

顾衡：“你们开门，下一股冲到谁家？”

阿澈：“我要知道里面是谁。也要知道她离开以后谁会受伤。”

Demo 在这句之后结束并保存。完整版由林月和姐姐留下守炉门，玩家点“跟顾衡下山，查清村符为何会裂”进入 G01。首发不再分成三个互斥路线。

## 卷二：山下那份账

### G01 两处旧灾

地点：南沟、东坡。老妇讲儿子背她逃，工匠说东坡那夜只下雨。顾衡的呈报写“全村同时遇险”。

玩家在入村时听到老妇与工匠的不同说法，随后可以先比两地留下的护符，或去旧钟楼查原簿。调查菜单有两条取证路线；取得两种独立来源之后，才可选择请顾衡当众核对呈报。revision 42菜单正文随旧符／原簿的收集情况更新，入口不提前置g.oldCharm／g.bellBook，完成取证的结果页仍用既有变量置位。单凭一位证人、一张符或术法沉默，不能直接断言十年前整个村子发生了什么。

### G02 辨不出的十年前

地点：工匠家。玩家用辨气触旧符，术法没有反应。旁白不说“没反应所以无灵潮”。

# 《崂山道士》AVG 游戏剧本

**改编来源：**蒲松龄《聊斋志异·崂山道士》原篇（[古文岛原文](https://www.guwendao.net/guwen/bookv_46653FD803893E4F3806D1A1596B4928.aspx)）。蒲松龄卒于 1715 年，原作已进入公有领域。本剧本保留原篇从王生求道到撞墙归家的全部事件顺序和结局；以下对白、旁白和场景说明重新创作，不使用网站的译文或现代改写。

**形式：**单线视觉小说，王生为主角。玩家点击观察和继续阅读；两次对墙施术按原篇先失败、后成功的顺序发生。原篇没有分支结局，本剧本不为凑选项新增案件、人物或另一种结局。

**预计长度：**约十五至二十五分钟的短篇章节，具体仍需试玩计时。它不能单独支撑《问心劫》多周目累计六小时的新鲜体验，只能作为独立短篇素材。

## 场景一：上山

**地点／画面：**清晨，崂山山道。石阶上有露，云从山腰缓缓散开。王生背着书箱，衣摆沾泥。

**旁白：**王生排行第七，家境宽裕，自幼听过许多仙人故事。他读得进书，却总觉得书页外还有另一条路。有人说崂山住着得道之士，他便背上行囊，一路问到山中。

**王生（心声）：**“倘若世上真有人能脱去凡俗，我总得亲眼看看。”

**演出：**山路尽头出现一座幽静道观。院内没有迎客的童子，只有一名白发道士坐在蒲团上。王生放下书箱，整衣行礼。

**王生：**“学生远来求道，愿拜先生为师。”

**道士：**“山里没有你想的清闲。能听玄谈的人多，能做苦工的人少。你养尊处优，恐怕留不住。”

**王生：**“请先让我留下。苦不苦，做过才知道。”

**演出：**日暮，观中门人陆续归来。王生随众叩拜。道士没有再劝，给了他一处睡觉的角落。

**推进：**玩家点击“留在观中”，进入次日清晨。此处没有离山分支。

## 场景二：斧头

**地点／画面：**道观后院、山林，连续数日。

**演出：**天还没亮，道士把斧头递给王生。其他门人已背好柴绳，走向山坡。

**道士：**“今日跟他们去采柴。”

**王生：**“先采柴？弟子还没学过吐纳。”

**道士：**“先把斧头拿稳。”

**旁白：**第一日，王生以为这是入门的考验。第十日，他还在砍柴。过了一个多月，他的掌心磨出厚茧，夜里举筷时手也发抖。师父谈道理时，他听得入迷；轮到自己，仍是清晨上山、薄暮背柴回来。

**可观察细节：**点击手掌，看到新茧压着旧茧；点击斧刃，看到王生终于能找到木纹，劈柴比初来时稳。观察只改变一两句心声，不改变原篇事件。

**王生（心声）：**“我若现在回去，家中不会少我这一担柴。可我走了，山上的仙术便与我无关了。”

**演出：**他把打好的包裹搁在床边，没有立刻拿走。院中忽然传来笑声。

## 场景三：纸月

**地点／画面：**道观厅堂，夜。两名客人与道士对坐，四周没有灯。

**旁白：**王生循声走到厅前。天色已暗，厅里却没有点烛。道士剪下一轮圆纸，贴在墙上。纸边刚贴平，屋里便亮了。

**演出：**不是烛火，也不是窗外月光。冷白的光从墙上的纸月铺开，案角、杯沿和每个人的眉目都看得分明。众门人围在门边，看得忘了说话。

**王生（心声）：**“一张纸，照得比真月还亮。我日日背柴，他却只抬了抬手。”

**客人甲：**“这样好的夜色，让小徒们也喝一杯吧。”

**演出：**客人拿起案上的酒壶，叫众人取碗。王生看见七八只碗一同伸来，担心一小壶酒转眼见底。他饮完自己的，又见下一只碗添满；众人轮流倒了几回，壶中的酒仍不见少。

**王生：**“师父，这酒壶里究竟装了多少？”

**道士：**“你今晚只管饮。明早柴山还在。”

**推进：**玩家按顺序观察纸月与酒壶，听到下一位客人的提议。

## 场景四：月中来客

**地点／画面：**仍在厅堂。纸月高悬，众门人微醺。

**客人乙：**“有月、有酒，怎么能少了歌舞？”

**演出：**他把一根筷子抛向墙上的纸月。月光里现出一名极小的舞者，落地时长到常人身量。衣袖转过案前，众人的影子在地上随她移动。她唱完一曲，旋身跃回桌上；王生眨眼再看，桌边只剩那根筷子。

**王生（心声）：**“她从哪里来？纸月后真有一座宫殿，还是我们都喝醉了？”

**客人甲：**“我已不胜酒力。可愿到月中送我一程？”

**演出：**道士与两名客人连席移入月光。王生隔着满室的人，仍看得见三人在圆月里举杯，连胡须都清晰。灯烛被门人点亮的瞬间，纸月暗下去。厅内只剩道士一人，案上的残酒与果壳却还在。

**道士：**“酒可尽兴了？”

**门人们：**“尽兴了。”

**道士：**“那便早睡。明日照常采柴。”

**旁白：**王生刚要收拾行囊的念头，又被今晚的月光压了回去。他不再觉得砍柴是白费日子：至少，这座山里真有他想学的东西。

## 场景五：又一个月

**地点／画面：**山林、道观。春雨浸透柴堆，王生的手掌开裂。

**旁白：**王生又留了一个月。斧头越握越顺手，道士却仍未传他一门术法。纸月之夜像隔着很远的梦；清晨的柴绳却每天勒在肩上。他终于去向道士辞行。

**王生：**“弟子从数百里外来，原想求得长生。如今不敢奢望，只求师父教一点小术，好让我知道这两个月没有白来。”

**道士：**“我初见你时便说过，你未必吃得住这样的苦。明早送你下山。”

**王生：**“下山之前，可否教我一术？”

**道士：**“你想学什么？”

**王生：**“我常见师父出入厅堂，墙壁挡不住您。若只学这一样，我便知足。”

**演出：**道士看了看他裂开的手，没有再谈长生，带他到一面实墙前。

## 场景六：第一次碰壁

**地点／画面：**道观外墙，白日。墙面粗糙，砖缝里生着苔。

**道士：**“记住口诀。念完，向墙走去。”

**旁白：**王生照着念了。他站在墙前，伸手摸了摸砖，砖冷而硬。道士叫他试，他慢慢向前迈步，肩膀先撞在墙上。

**王生：**“弟子念错了吗？”

**道士：**“你眼里只有这堵墙。低头，退开几步，走过去。别站在半途犹豫。”

**交互：**玩家按提示让王生退开、俯首、向前；第一次迟疑受阻不可跳过。

**演出：**脚步声急了。王生以为又会碰到冰冷的砖，迎面却像穿过一阵空风。他猛地回头，墙已在身后。他伸手确认自己不是绕了路，笑得几乎说不出话。

**王生：**“真过来了！”

**道士：**“回家后持身清正，才用得出。记住我这句话。”

**旁白：**道士给了他回乡的盘缠。王生再拜，带着口诀下山。他心里记得穿墙的感觉，却更急着让别人看见。

## 场景七：回家

**地点／画面：**王生家中。熟悉的院墙，妻子正收拾箱笼。

**妻子：**“你终于回来了。学到了什么？”

**王生：**“师父是真仙。他抬手能把纸变成月亮，酒壶怎么倒都不空。我也学了一样本事——这院墙挡不住我。”

**妻子：**“你是一路走累了，还是想叫我替你开门？”

**王生：**“你站远些，看着便知。”

**旁白：**王生退到院中。他想着道观里自己从墙另一边回头的那一刻，妻子却在旁边看着。他想把那一刻做得更利落，好叫她相信自己确实遇见了仙人。

**演出：**王生念咒，俯身冲向墙。镜头跟着他的脚步向前，到了墙前忽然停住。响声过后，他跌坐在地，额头鼓起一大块。

**妻子：**“墙没学会躲你。”

**王生：**“那道士明明教我穿过一次……”

**妻子：**“你先把头上的伤敷了，再骂人吧。”

**旁白：**王生恼得脸红，抱怨师父骗他。妻子扶他进屋，院墙仍立在原处。他确实曾在山上穿过去，也确实在家里撞得不轻。道士临别说的“持身清正”，他没有问明白；这一次失败究竟是心术、修行不足，还是术法只在山中有效，他也说不准。

## 尾声：墙

**画面：**夜，院墙的影子落在王生关上的房门前。

**旁白：**他上山是为了求长生，走时却只挑了一样能让旁人惊讶的小术。见过纸月、无尽的酒和月中的舞者，他记得最牢的，是自己终于能穿过一面墙。回到家，墙又成了墙。

**结算：**播放短篇结束页。可回看道士初见时的劝告、两个月的采柴、月宴和临别告诫；没有“成功穿过家墙”的隐藏结局。

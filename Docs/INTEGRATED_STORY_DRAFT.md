# 《问心劫》全程剧本结构初稿

状态：供制作与评审的具体方案，尚未成为不可更改的设定。正式入口已录入一版简短的三路调查、裂隙试验与结局结构；本稿大量场景细节仍未实现。体验目标见 `GAME_REDESIGN.md`，已实现范围见 `DEVELOPMENT_STATUS.md`。旧十日切片只提供人物和事实素材；此前临时命名的新案不直接续写。

## 贯穿全剧的事实（需要在场景中逐步查明）

十年前山脉裂隙使青云山下村落的灵脉失稳。宗门设旧阵，把裂隙冲击引向炉中的“息位”。有修为的人能随冲击自行调整气息，因此比石符更能吸收不规则的阵压；宗门以登仙考校征选承压者。炉中的人并非每次都会死，但会受伤、失忆或失去修为。宗门把被编入息位的人从公开名册中注销，以死亡、失踪或“出山”掩盖去向。此事有宗门高层主动隐瞒，也有知道部分真相、认为暂时别无办法的人。

登仙帖上的朱印是一张可复用息位凭证。它选择的是与旧阵相容的气息，不是主角的独特血脉；历届曾有其他相容者。沈砚当年参与绘制调息部分，第一次试阵后发现承压上限被宗门改高，选择伪造死亡逃离并保存底稿。他对最初建立人息位负有责任，逃离后又长期没能救出炉中人。主角持有他的旧帖，是宗门复用已注销凭证的结果。名字、凭证、当前承压者可能是三个人，不可据一份账册自动等同。

旧阵骤停会把尚未消散的阵压沿地脉副线送向村落。顾衡掌握历次村落护符耗损，知道危险真实存在，却没有把“由谁承压”充分告知村民。近期护符裂纹、炉灰增长与阵眼频率共同表明，下一次灵潮前必须补位或改阵；具体时日要由玩家在剧情中测得，不预先规定三十日。替阵可用废弃副脉和村落护符分流，但必须先撤出部分村民、在炉边稳住活人、有人手动调节首轮阵压，并让各方知道风险。它不是一张万能新图。

这些事实是编剧用的底层答案，不应由单人独白交代。每项重要结论至少有两类来源可以互相核验；每位角色都只能证明自己实际接触过的部分。

## 共同开局：让玩家拥有第一个问题

1. **司籍差事**：主角誊录新弟子去向，发现自己的登仙帖背面被刮去旧名，卷宗却把对应旧号写作“死亡注销”。玩家先选择保留原帖痕迹、查注销抄页，或询问交接人；三条路径都能提出疑问，却取得不同质量的证据并引发不同注意。
2. **第一轮解释**：呈现可理解的三种可能——旧帖误发、死者仍活、有人借注销编号处理物资。此时不告诉玩家哪项正确，也不立即让林月送来术法和沈砚本人。玩家选要验证哪一处矛盾；选择不是一次答题，而是决定先追哪条证据。
3. **术法获得**：主角已有炼气基础，可从司籍房留存的入门册学习辨气的基本法门；林月或其他人可以指点，但要有她自己的条件与隐瞒。玩家在可核对的新旧印记上练习成功后，才能用于真正可疑的物证。辨气只能证明气息新旧与流向，不直接证明炉内活人身份。
4. **第一次对质**：管事、林月和另一名见过运灰车的人给出不完全一致的说法。玩家可拿具体证据追问，也可先保全原件；过早指控会让原账被封，但仍可通过转运人或残灰继续。第一次对质应改变后续证人和地点，不能只显示“宗门注意+1”。
5. **开局揭示**：玩家发现旧号今天仍被使用，但尚无法判定持帖人、账中人和炉中人是否相同。问题升级为“旧号实际在替谁承压”，自然进入三种调查立场。

## 三条可完成一周目的调查路线

路线由玩家为了当前问题选择的合作对象与取证方法逐渐形成，而非开局选阵营按钮。任何路线都能查到足以理解旧阵与终局风险的共同核心事实；不同的是具体身份、历史责任与可用人手。若某路线因玩家失误失去原计划，要提供有代价的替代入口。

### 林月：谁还活着

主要场景：弟子居所、运灰小径、炉房外侧、临时藏身处。她掌握几名失踪弟子的亲友和可能撤离路线，却不知道完整阵图。玩家追查账中旧号时遇到阿澈；他确实见过炉内活人，但长期受药与阵压影响，混淆了某人的姓名和被带走顺序。玩家需比对运灰时辰、个人随身物、炉房轮值和阿澈的证词，才能确认具体谁仍在炉中。

玩家可先救阿澈取得活人证词，代价是让守卫警觉、失去抄完整原账的窗口；或先取原账，代价是阿澈在下一次轮值前仍暴露于阵压。两条选择都继续：前者可向家属核对姓名，后者可凭原账定位并组织后来救援。学到或改进的符箓可短时隔绝巡守阵眼，但不能使整座炉房失效。林月会要求先撤人；玩家如果还没确认村落风险，不能由剧情替其认定停炉安全。

林月的弧线是从“只要开炉就是救人”走到承认自己也必须对山下人负责，但不会因此接受继续牺牲弟子。她是否愿意同顾衡合作取决于玩家是否向她呈现经过验证的村落风险，以及顾衡是否允许活人名单公开。

### 顾衡：谁会承受停炉

主要场景：山下村落、护符工坊、旧灾碑、阵眼外观测台。村民有不同立场：有人亲历旧灾，怕主角救炉中人时放出裂隙；也有人发现护符背面的领用标记与失踪者姓名相连，质问自己被保护的代价。顾衡说“停炉会伤村”，但他提供的最初数字经过保守放大。玩家可以查护符裂纹、旧灾伤亡和一次短暂停炉后的灵脉记录，再用阵理试算，区分真实危险与顾衡的遮掩。

顾衡可提供受监督的炉房查验和撤村人手，代价是林月的秘密接人窗口缩小。玩家若把村民当成可隐瞒的受益者，会失去撤村协作；若公开全部未经核实的炉房姓名，可能使守卫先封炉。顾衡的弧线是承认保护村民不能剥夺村民了解代价的权利，同时仍坚持替阵必须经实测。玩家若拿出经核验的分流方案，他可以成为执行者，而非阻挠者。

### 沈砚：旧阵是谁设计成这样

主要场景：废弃测绘房、封存图库、旧试阵地点、地脉副线。玩家不应在开局被林月直接带去见沈砚，而是在记录、图纸或他留下的错误修正中逐步确认他还活着。他保存了未被修改的底稿，却删去了自己同意建立第一批人息位的签名。玩家通过两版阵图、当年炉灰上限与幸存者记忆对质，决定是否让他参与下一次试验、应向谁坦白责任。

沈砚能教玩家阵理和局部分流，但他的计算需要真实的村落与炉房载荷。只信他的图会在试验中发现一个缺失的副脉回流点，付出可见但可补救的损失；这不是随机失败。玩家可选择公开他的旧罪换取多方监督，或暂时保密以争取试验时间，但终局仍须处理责任。沈砚的弧线不是洗白，而是从替自己赎罪转向接受被他伤害的人有权拒绝他的方案。

## 汇合：三种立场必须相互校验

玩家沿任一路线调查后，都会得到“炉中仍有人承压、骤停会伤村、宗门准备续阵”三项核心事实，但证据可信度和掌握的执行条件不同。结局前有一段由玩家主导的交叉核验：可以让阿澈与原账对照姓名、让顾衡的阵压数字接受实测、让沈砚底稿与村落护符相互验证。至少一项因前面失误而无法直接取得时，可承担明确代价从另一入口补足；不能把玩家卡在无意义的正确答案考试里。

替阵小试验由玩家实际选择稳住哪一处、使用哪项已学术法、谁在场作证。试验即使未成功，也要留下可靠的新测量，解释哪里超出上限。林月的撤人、顾衡的撤村、沈砚的分流图彼此不能独立解决全部问题；玩家从这三者中组成可执行方案。合作程度来自此前兑现的承诺，不是刷满信任值。

## 终局四方向与代价预告

终局之前，玩家可查看已验证的条件与每方案的主要风险，相关人物会就自己知道的事实提出异议。四方向是候选，不是已实现结局，也不是按总分自动发放。

| 方向 | 玩家亲自执行的行动 | 必须事先提示的代价 | 结局要交代 |
| --- | --- | --- | --- |
| 替阵救众 | 撤出炉中人，分流旧阵，利用符箓争取时间，亲自调节首轮阵压；请村民参与知情撤离 | 主角可能损失修为，村落须短期迁离，沈砚须面对公开追责；准备不足会扩大损失 | 被救弟子如何恢复、村落如何生活、新阵由谁监督，旧罪是否公开 |
| 携人离山 | 先按可靠名单救出能接近的人，并组织愿意撤离的村民，不承担改阵承诺 | 旧阵仍会失控或被宗门继续征人；未走的人承受后果 | 哪些人逃脱、哪些人留下、主角是否承担告知与后续救援责任 |
| 夺炉自立 | 控制阵眼，决定把阵压转向自己、宗门执事或其他承压者 | 强行控制可能使主角获得力量也成为新的强制者；不能隐去他人承压 | 权力由谁制衡、被迫承压者是谁、保护与剥削是否换了主人 |
| 维持旧阵 | 稳住裂隙、推迟续阵崩溃，选择是否公开真实代价并争取减损 | 村民暂安全，炉中人的牺牲继续，主角成为知情参与者 | 牺牲者、受保护者和宗门责任如何被记载，主角是否留下改变的路径 |

理想方向不等于无代价；其他方向也不能只用惩罚性坏结局敷衍。玩家只靠第一周目就能理解自己的选择；另一路线提供新角度和新的行动办法，而不是把真相藏到多周目后才允许做“正确选择”。

## 录入剧情数据之前的交付物

下一步把每个场景写成可核对的场景卡：玩家进入时知道什么，场景给出哪条原始证据，玩家能选择哪些验证办法，错误判断产生什么即时与后续后果，离开时开放哪些新地点。先完成共同开局、三条路线的专属中段、汇合试验和四结局的完整对白与行动稿，再决定如何替换现有 JSON 节点。`Campaign.json` 当前草稿与旧十日内容应在新稿审查后逐段改写，不能机械续接。

## 第一轮场景卡：共同开局

场景卡描述玩家可做什么与剧情必须回应什么，尚非正式对白。场景 ID 只用于沟通，不承诺代码节点数量。

| 场景 | 进入时玩家所知与可见证据 | 玩家行动和离场变化 |
| --- | --- | --- |
| 开一：交接差事 | 登仙帖背面有刮痕，新名册中一批人的去向栏空白；执事命主角校对回执 | 可先保全帖子、先看空白栏、或问交接人。不同顺序改变是否留下原始刮痕与谁知道主角起疑；都指向司籍副页 |
| 开二：副页矛盾 | 一张旧帖的凭证号与十年前注销副页相同，副页把沈砚写作死亡；号码未必等于姓名 | 玩家选择查纸张、查印、查归档记号。纸张提示旧帖曾再次使用；印记提示今天有人动过封；归档记号指向炉房，但都不能直接证明沈砚在炉里 |
| 开三：回执到房 | 本旬养息灰回执仍沿用旧凭证号；管事称只是账面沿用，送灰弟子称运灰车今天从炉房返出 | 玩家可抄录回执、请求原账或留下炉灰样本。强索原账会触发封存，却能从封存单看到负责人的签名；温和核对能保全完整回执但暂时拿不到原账 |
| 开四：辨气练习 | 司籍房有《辨气入门》；同一砚台上放着主角刚按的朱印和昨日旧印 | 玩家亲手选两印练习，确定辨气只能看到时间和流向。用在回执灰上只能发现近期有两道混杂气息，不能分辨人名或炉内人数 |
| 开五：第一次判断 | 当前有“死者旧号、今日回执、混杂气息”，仍有误抄、借号或沈砚未死等解释 | 玩家明确选择先追人、追账或追阵痕；说错不会立刻失败，但会使相应证人准备说辞或守卫收紧入口。路线选择是下一步取证方式，不是最终阵营 |
| 开六：交叉反证 | 司籍封存单、运灰轮值、林月所留的旧玉扣可按前面选择取得两项；两项足以排除纯粹旧账，但仍不能确认炉中身份 | 玩家把具体证据拿去质问管事、林月或送灰弟子。被质问者只回应自己实际知道的部分；主角首次看见人的说法可被证据限制 |
| 开七：山腹异动 | 村落护符在一次小震后开裂，炉房同夜额外领灰；期限开始有可观察的因果 | 玩家决定继续藏查、申请顾衡的受监督查验，或寻找沈砚留下的测绘痕。三种入口开放，均通往完整游戏 |

开局必须保留一个明确悬念：谁正使用被注销的旧号，炉中的人是谁。当前新案草稿让林月过早交出术法并带来沈砚本人，会把这道问题替玩家回答；正式改写应让玩家靠选择的证据进入下一案。

每条路线至少需要以下九个不同功能的场景。实际录入时可拆成更多对白节点和调查互动；不要把表格一行当作一屏叙述。

| 顾六：村民知情 | 玩家向代表村民展示经过核实的成本，决定公开个人姓名的范围。公开得过早会使家属冲炉，隐瞒则失去后来撤村的同意 |
| 顾七：受监督查炉 | 顾衡开合法入口，林月担心守卫转移活人。玩家可要求见证者、先保全灰样或安排林月堵转运路，每种取证不同 |
| 顾八：撤村演练 | 玩家带村民试走一条山道，发现老弱无法按顾衡计划速度离开；须修改替阵时间与人手，而不只是获得“撤离成功”旗标 |
| 顾九：跨路线求证 | 顾衡提供护符与撤村准备，要求先核实炉中人数；玩家可请林月带证人，或找沈砚核对底稿，不得无证承诺骤停 |

| 沈砚路线 | 原始证据、主动验证与后果 |
| --- | --- |
| 沈一：测绘笔迹 | 旧册边缘有同一种修正手法，指向沈砚的绘图而非他的当前行踪。玩家用笔迹、印泥和日期排除伪造可能 |
| 沈二：废测绘房 | 封存柜中有两版阵图，旧版载荷上限较低。拿走图纸会惊动宗门，拓印则失去部分尺寸，需要之后实测补齐 |
| 沈三：见到活人 | 玩家凭底稿上的藏身记号找到沈砚，而非由林月直接引见。此时仍不知他对第一批承压者知情多少 |
| 沈四：旧罪对质 | 沈砚说上限由宗门改高；玩家出示他签署的人息位初案，逼他承认自己最初也同意让弟子入阵 |
| 沈五：阵理进阶 | 玩家与沈砚复现一段废弃副脉，亲手选测点；一处回流超出底稿，表明他的图并不完整 |
| 沈六：谁作见证 | 沈砚希望先试验再公开旧罪。玩家决定是否让林月、顾衡或承压者家属在场；监督提高可信度但推迟试验 |
| 沈七：局部试验 | 玩家选择符箓先护住炉边或村口。未护一侧承受可见损失，试验仍留下回流测量，后续方案因此改变 |
| 沈八：承担责任 | 沈砚愿亲自承压，林月质疑这仍是他替别人决定。玩家应取得当事人同意，或拒绝把赎罪当作技术条件 |
| 沈九：跨路线求证 | 沈砚提供修正后的分流图，需要活人数量与村落护符余量。玩家向林月、顾衡取数或用更危险的现场测量补足 |

## 第一轮场景卡：汇合与高潮

| 场景 | 玩家必须执行的步骤及分支兑现 |
| --- | --- |
| 汇一：三项共同事实 | 玩家整理可确定的活人、停炉风险与续阵时间；未走路线的细节可缺，但必须能从当前路线加一次有代价的补证取得足够决策信息 |
| 汇二：公开范围 | 玩家决定让哪些人知情。承压者姓名、村落风险与沈砚旧罪可分别公开，不能用一个“公开真相”按钮概括三件事 |
| 汇三：撤人和撤村 | 具体名单与山路条件影响谁来得及离开；之前救阿澈、演练村路或保全原账会改变可行人数与冲突 |
| 汇四：替阵复测 | 玩家选择观测点、符箓保护目标和参与者，对照旧阵实际回流。一次错误判断应造成局部损失与改进机会，而非突然全灭 |
| 汇五：方案争论 | 林月、顾衡、沈砚各自拿可验证事实反对不充分的方案。玩家可改变准备，或在理解风险后坚持原案 |
| 汇六：终局执行 | 玩家在炉门、村落、副脉三个地点分别安排人手和行动；根据前面证据与承诺执行替阵、撤离、夺炉或维持，而非只点结局按钮 |
| 汇七：后果追踪 | 结局中逐一回访炉中弟子、村民和三名主要人物；承认主角的能力改变了什么，也指出不能由术法抹掉的责任 |
